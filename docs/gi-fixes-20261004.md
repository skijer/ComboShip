# ComboShip GI and item fixes for October 4 2026

User-approved implementation scope. Parent baseline: PR 34, commit
`122dd5f68cb37fcf515c3726f8a77043db5dcdf4`. Candidate branch:
`poc/gi-fix-batch-20261004`. This document tracks implementation and evidence;
it does not declare runtime acceptance or master promotion.

## Preservation contract

- Preserve the approved swords, gold-bladed True Master Sword, held equipment,
  weather-only season GIs, detailed receipts and progressive item identity.
- User O2R/Alt/player model replacements remain authoritative, including partial
  opaque/translucent replacements. Keep the Pegasus boot attachment.

  game hosts. Do not introduce diagnostic-only functionality.
- Keep runtime proof distinct from compiled tests and offline model previews.

## Implementation plan

1. Repair Rod of Seasons placement, MM extended D-pad identity/use and consumed
   randomized shop slots. Preserve existing first-season rod grant; implement
   real MM seasonal weather through MM environment and item-use APIs.
2. Repair item icon and foreign GI routing at their source. Add missing Lantern,
   Poké Ball and Mario Mask export recipes without weakening mod priority.
3. Extend acquisition receipts with counters, descriptive songs and requested
   colors. Implement Maps and Compasses Give Information across collection and
   owned-item pause descriptions, including actual boss rewards, shuffled boss
   destinations, inverse dungeon-entrance locations and pedestal hint gating.
   Preserve three-line MM pagination and ordinary/masterful dungeon hints.
4. Apply item-specific shimmer and bounded GI transforms/effects. Keep authored
   model source and held transforms unchanged unless specifically requested.
5. Author the new requested models, close Slate sides and derive matching HD
   inventory assets; validate serialized resources and inspect offline previews.
6. Run relevant tests and the Combo NEI regression gate, review all changes,
   identify remaining runtime checks and preserve a recoverable candidate.

## Clarifications incorporated during implementation

- The original MM code had a rod inventory entry and season grants, but no rod
  input/menu runtime. Missing HUD behavior is explained by that missing port.
  New input draws the rod on the first equipped-button press and opens the season
  selector on the second. Native item-change completion must precede drawing.
- The seasonal snow review concerns actual MM ObjectKankyo weather actors,
  not the accepted seasonal get-item illustrations. Their existing GI weather
  palette remains separate from gameplay weather.
- The Fairy Bottle should use the selected TP **blue-fire** shell resource,
  not assume that the generic empty bottle is the same mesh. The blue flame is
  replaced by a bouncing pink fairy effect, with pink shimmer.
- Maps and Compasses Give Information is a requested new saved setting in this
  fork. When enabled, compass information includes the actual reward behind the
  resolved boss, and map information names the physical entrance location.
  Starting with these items must expose the same information without a pickup.
  Pedestal progression requirements remain; only its reward-location hints yield.

## Candidate behavior

The requested code and asset changes are implemented except for Kokiri's
configuration-specific flat pose. Both built-in Kokiri GI meshes are upright;
the selected external hand-space replacement and its active transform must be
identified before changing that protected path. Bongo and the accepted TP
Volvagia head are preserved as clarified. Volvagia's GI explicitly selects the
head skeleton; its full actor body uses 18 separately simulated segments, and
there is no evidence that a model-size limit forced the original choice.

### Rod, D-pad and shops

- MM now has real rod input, a held model and a season selector. Press the
  equipped C or D-pad button once to draw, then again to open the selector.
  A confirms an unlocked season or Off; B cancels. Native item-change completion
  precedes drawing when another item is already in hand.
- Only seasons enter the new MM pool; the existing first-season grant supplies
  the rod. Legacy standalone rod IDs remain readable. Extended D-pad identity
  stays 16-bit across equip, swaps, icon refresh and save/reload. A native
  Mushroom remains a Mushroom.
- Both MM season fields are now serialized. Older saves with absent fields
  default to zero; a rod alone cannot prove which lost season was owned.
  Existing cross-game ownership synchronization is retained.
- Spring uses green drifting particles, Summer clears seasonal precipitation,
  Autumn brings rain, and Winter brings native snow/overcast and human
  water-surface support. Off restores native weather. Native story/cutscene,
  interior and underwater restrictions remain. The accepted season GI artwork
  is separate from these gameplay effects.
- Consumed randomized shops restore their exact original native stock and
  behavior, including OoT Bombchu variants. Stale randomized callbacks cannot
  charge or grant twice. Native stock still follows its own sold-out rules.

### Map and compass information

- **Maps and Compasses Give Information** is a saved option under Static Hints.
  It defaults off for existing saves and old seed snapshots. Enable it when
  generating a seed to use the requested information behavior.
- OoT compasses resolve the actual shuffled destination boss and then that
  boss's placed reward, including ordinary items and foreign rewards. Well and
  Ice Cavern have no boss-reward hint. Maps resolve the physical source entrance
  through the saved entrance mapping. The existing ordinary/masterful hint
  remains, including when OoT has not yet been entered.
- Pickup and owned-item pause descriptions share the same information. Start
  With ownership works without pickup history. On the current dungeon map
  page, select the owned item and use **C-Up in OoT** or **A in MM**. This does
  not add a new overworld dungeon selector.
- MM uses its actual four boss-warp reward placements and its known native
  bosses/entrance locations. This fork has no MM or cross-game boss/dungeon
  entrance shuffle provider; no hypothetical mapping was invented. MM Maps
  and Compasses received in OoT use the same information.
- Enabling the option replaces pedestal reward-location hints while retaining
  Door of Time, bridge, boss-key, soul and victory requirements. Newly generated
  Combo altar hints and previously baked Hint Tracker payloads follow the same
  rule. Loaded tracker text is normalized from a copy; saved seed/read-key data
  is unchanged. No grant,
  progressive item resolution or entrance-discovery state is changed by asking
  for information.

  the blue-rupee fallback. Somaria is red, Pacci gold, Poké Ball red/white; masks
  use individual palettes and Goht uses red shimmer/text. Magic upgrade names
  are green. These are requested changes to the port, not claims about original
  console text colors.
- Fairy Bottle prefers a fairy-specific override, then the selected OoT TP
  Blue Fire shell, then a selected generic bottle shell, then its native shell.

  retain a native fallback with one shimmer. See the companion fairy document
  for exact replacement paths and fallback rules.
- MM song notes have matching shimmer/text colors and correctly formatted,
  unstretched receipt icons. Song of Storms uses local rain/lightning effects.
  Native/foreign Skulltula receipts select the correct house counter.
  Double Defense exports the heart-container icon rather than the colliding
  Fish ID.
- Four Sword pickup model/effects are lowered 18 GI-local units; held geometry
  and Pegasus attachments are protected. Morpha keeps its eye/core/flame and
  drops the tentacle. Cute Cojiro and Mario Mask models are authored from
  reproducible source. Cojiro is an optional asset-only O2R, absent from both
  built-in game asset trees; Mario Mask remains bundled. Six Slate side walls and handle mounts have corrected
