## Cosmetic routing

Both primary and secondary editor values are sampled afresh for every draw. Primary colors the bright core; secondary colors the outer energy. Edited shimmer follows secondary, or primary when only primary is edited. Reset restores the authored colors and default hex shimmer. Picker alpha does not change visibility.

| GI | OoT editor pair | MM editor pair |
| --- | --- | --- |
| Fire arrow | `Arrows.FirePrimary/FireSecondary` | `Effects.FireArrowPrim/FireArrowSec` |
| Ice arrow | `Arrows.IcePrimary/IceSecondary` | `Effects.IceArrowPrim/IceArrowSec` |
| Light arrow | `Arrows.LightPrimary/LightSecondary` | `Effects.LightArrowPrim/LightArrowSec` |

OoT keys use `gCosmetics.*.Value`; MM keys use `gCosmetic.*.Color`. Changed/Rainbow flags belong to the same base key. Foreign descriptors select their item's owning editor namespace, including MM-owned copies of the three spells placed in OoT. The shared editor sync table now includes the added Farore/Nayru MM rows. Both donor samplers advance only a resource-only rainbow clock; they never tick a dormant engine or apply dormant asset patches.

## Held and shelf fit

Held receipts inherit the caller's native scale, origin and rotation. Arrow cores keep native/Alt resource selection and the original diagonal orientation. Shop arrows reduce only tip emission to 75%; shop crystals reduce shell, contents and shimmer together to 82%. Both native and foreign shop dispatches carry that context. Effects have one intrinsic shimmer even when optional Item Effects is off.

The complete elemental effect is admitted before its first submission. A spell declines to its native fallback when a graphics arena is short; fallback admission reserves the real scroll allocation, one matrix, and segment restoration. The arrow core can remain visible when its effect declines. Native shop core admission includes the XLU debug markers generated by OPA setup. Existing NEI surface sheen has separate admission so it can decline while the intact core/shell still draws. Every effect restores modelview, resource ownership, grayscale and colors. Six-crystal shelf tests cover both engines' real arena layouts; the broader eight-item shelf retains its 80 KiB vertex and 2700 XLU-command limits, allowing the three extra sheen/restore matrix pairs.

The eight-item fixture measured 74,224 effect-vertex bytes, 2,374 XLU commands, and 36 matrices. The focused native MM arrow renderer peaked at 12,144 OPA bytes and 382 XLU commands for one GI. These are fixture measurements, not game-frame timings.

## Reproduce the offline preview

```sh
c++ -std=c++20 -O2 -Isoh tools/elemental_spell_gi/export_preview.cpp -o export-elemental
./export-elemental elemental-preview.bin
python3 -B tools/elemental_spell_gi/render_preview.py elemental-preview.bin PATH_TO_OOT.o2r OUTPUT
```

The exporter samples the exact production meshes at native fixed-point position and UV precision. The preview decodes the native arrow's actual vertex positions, triangles, primitive/environment colors, generated/manual UVs and reflective I8 material from the supplied archive. It uses the shipped GLB checkpoints for the existing NEI models and production textures, I8 hot/edge palettes, glass ordering and standard alpha blending for effects. Lighting is an offline approximation; pack-specific arrow replacements are not pictured. The 24-second loop spans 720 game ticks in three-tick steps, covering the combined 360-tick geometry and 48-tick cloud periods. Default, elemental shelf-footprint and purple/green cosmetic stills use canonical views. The third row shows the existing NEI crystal casing at its canonical size; the six-element color example does not alter their existing palettes. They are isolated presentation previews, not screenshots of shelves or receipt cameras.
