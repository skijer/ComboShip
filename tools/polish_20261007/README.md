# ComboShip 2026-10-07 runtime review kit

For builds containing the October 12 bundled-key correction, all eight repaired
MM keys are included in `2ship.o2r` and render with Alt Assets on or off. The
standalone key archives below are historical source/recovery assets and are not
required by those builds. See `docs/poc/bundled-dungeon-keys-20261012.md`.

Use these assets with the matching daily-polish source build. The source carries the sword, autumn, tunic/Ikana, map/junk/song/key receipt, cape choice, rod, Shadow Crystal, arrow and bottle/boss/gold fixes.

Copy `mods/soh/` and `mods/2ship/` into the matching directories beside ComboShip. Enable the owning game's Alt Assets to select the bottle and custom dungeon-key packs. Replace older empty/potion POC packs and the old key-only POC3 archive; keep `rollback/` outside the active mods folders. Keep all other accepted scene and equipment packs in their existing load order. Elemental arrow and Shadow Crystal built-in resources are generated by the normal source build and do not need another mod archive.

The two bottle archives share the preserved POC3 casing and the POC4 marked liquid/shell recipes. The repaired key archive preserves all eight key bodies and corrects surface overlap. Its editable models and previous key archive are retained for recovery. `source/` contains the original bottle input used by `scripts/mods/build_shared_bottle_gi.py`.

Copy `Randomizer/01-MM-All-Equipment-Progressive-20261007.json` into the game's Randomizer directory. Drag it onto file select, then create a fresh MM randomizer save without generating another seed. The first seven pickups test all progressive sword tiers, and the first 44 cover all equipment. Turn item-cutscene skipping off and finish each receipt before the next pickup. `Pickup-Checklist.csv` and `Equipment-Review.txt` contain the complete 90-pickup route and optional control files.

Inspect native and foreign pickups with each owner’s Alt setting on/off: sword framing and one shimmer; three tunic models; upright Ikana shield and its MM icon; colored key receipts and unchanged grants; map single-box fit and compass reward icon; cape Show/Hide persistence; bottle glass/liquid/palette; native boss rigs across toggles. Inspect autumn depth/showers/foliage and Sand/Storm behavior in the intended scene packs. Shader/GPU visuals and gameplay acceptance remain separate from source and application build checks.
